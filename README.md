
### 2. Instalar as Dependências
```bash
npm install
```

## 🌐 Deploy na Hostinger (Node.js / VPS / Cloud)

Esta aplicação está configurada para deploy automático em hospedagens Node.js (como Hostinger, Render, Railway ou VPS):

1. **Repositório GitHub:** Conecte o repositório GitHub ao painel da Hostinger (Seção *Node.js* ou *Git*).
2. **Arquivo de Entrada (Entry File):** Configure `server.js`.
3. **Versão do Node.js:** Recomendado **Node.js 20.x** ou superior.
4. **Comando de Instalação (Install Command):**
   ```bash
   npm install
   ```
5. **Comando de Build (Build Command):**
   ```bash
   npm run build
   ```
6. **Comando de Inicialização (Start Command):**
   ```bash
   npm start
   ```
   *(ou `node server.js`)*

> **Nota de Resiliência:** O arquivo `server.js` conta com rotina de auto-build caso o servidor seja iniciado antes do comando de build, garantindo que os arquivos da pasta `dist/` sempre sejam servidos corretamente com fallback para `dist/index.html`.
